# 学术档案主页链接指引

> 目的：在 Google Scholar、LinkedIn、ORCID、arXiv 等学术档案中填写主页链接 `https://altairpaca.github.io/`，形成指向个人主页的外部反链，帮助搜索引擎更快发现并信任主页内容。
>
> 本节全部为**账户级手动操作**，需您本人登录对应平台完成。预计耗时 10–15 分钟。

---

## 1. Google Scholar（必做）

- **档案地址（现有资料，11 次引用）**：https://scholar.google.com/citations?user=md5Z-D8AAAAJ
- **操作路径**：
  1. 登录 Google 账号后打开上述链接，进入自己的 Scholar 档案页；
  2. 点击页面右侧或资料卡中的 **「编辑」**（Edit）按钮；
  3. 在编辑表单中找到 **「网站」**（Website / 首页）字段；
  4. 填入主页地址：`https://altairpaca.github.io/`；
  5. 点击 **「保存」**（Save）。
- **完成检查**：重新打开档案页，资料卡头像下方的「网站」一栏应显示主页链接，点击可跳转到 `https://altairpaca.github.io/`。

## 2. LinkedIn（必做）

- **资料地址（现有资料）**：https://www.linkedin.com/in/altair-li-2a2bb0307/
- **操作路径**：
  1. 登录 LinkedIn 后打开上述链接，进入自己的个人资料页；
  2. 点击资料卡右侧的 **「编辑公开资料和网址」** 或资料卡上的 **「添加简介部分」→「网站」**（若已存在则点击铅笔图标编辑）；
  3. 在 **「网站」** 字段确认或填入主页地址：`https://altairpaca.github.io/`（类型选 **「个人」** 或 **「作品」** 均可）；
  4. 点击 **「保存」**。
- **完成检查**：资料页「网站」一栏显示主页链接且点击可访问；若此前已填写，确认链接与上述地址一致即可。

## 3. 可选：ORCID 与 arXiv

### 3.1 ORCID 注册并添加主页链接（可选）

- **注册地址**：https://orcid.org/register
- **操作路径**：
  1. 用个人邮箱在 ORCID 注册账号并完成邮箱验证；
  2. 登录后在「个人信息」或 **「Websites & Social Links」** 区块点击 **「添加」**（Add）；
  3. 添加主页链接：`https://altairpaca.github.io/`（名称可填 `Personal Homepage`）；
  4. 点击 **「保存更改」**。
- **说明**：ORCID 为可选建议，不创建也不影响前面两步；注册后可将主页链接写入公开档案，作为学术身份标识的补充反链。

### 3.2 arXiv PLUTUS 作者页链接（可选）

- **论文地址**：https://arxiv.org/abs/2408.10111（PLUTUS）
- **操作路径**：
  1. 打开论文页面，点击页面中的作者姓名（如 Zhenzhuo Li）进入 **arXiv 作者页**；
  2. 若该页面提供「个人主页」编辑入口（arXiv 作者页由 arXiv 维护，通常仅允许作者通过注册账号补充公开信息），则将 **Homepage** 填为 `https://altairpaca.github.io/`；
  3. 若作者页不可编辑，则此步跳过，不影响其他档案。
- **说明**：arXiv 作者页一般**不可直接编辑**，仅在 arXiv 开通对应作者自维护功能时可用；ACM DL 与 dblp 的作者页由数据库自动生成，无需手动配置。
